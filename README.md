## 🧭 What Each Entry Contains

- **About the Profile** — summary of what public records describe
- **Key Characteristics** — feature grid, unverified fields marked
- **System Requirements** — Windows 10/11 (64-bit), modern GPU drivers, 100 MB disk
- **Download** — pointer to the project's public distribution page
- **Setup Notes** — launch order and overlay behavior
- **Disclaimer** — informational/research use only

| ✅ Verified | Traceable to a primary source |

## 🛠️ Deployment

Static HTML hosted via **GitHub Pages**. No build step required — push the
repository and enable Pages on the default branch. Each profile lives in its
own subdirectory with an `index.html`, and the root `index.html` serves as the
profile index.
